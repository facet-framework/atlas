The Atlas reader is generated, not committed. The binary you are talking to was compiled from a checkout that never built it, so only this page is embedded.

Build the reader, then rebuild the binary:

sh scripts/build.sh

To rebuild only the browser assets, use go generate ./backend/server. A released binary never shows this page; if you installed one and see it, that release is broken — please report it.
